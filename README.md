# Mazzuola

A small, fast modeller for static low-poly 3D models in the style of early PlayStation
games: few polygons, small hand-painted pixel textures, vertex colours. Made to work
alongside Scalpellino; exports `.glb`/`.gltf` and `.obj`.

Personal project. Nothing is built yet. See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
for the design and [`docs/PLAN.md`](docs/PLAN.md) for progress.
