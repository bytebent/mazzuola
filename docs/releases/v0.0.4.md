## Mazzuola v0.0.4 — paint window display test, round 2

v0.0.3 showed that the paint window keeps drawing on the iPad (the frame counter goes
up) but the iPad never shows the new pictures, with or without "Sync to display".
Two more switches in the paint window's left strip (Display test):

- **Refresh context**: before each frame, tells the window's OpenGL context to re-check
  which window and display it draws to.
- **Redisplay window**: after each frame, tells macOS the window's view needs showing
  again.

Try each on its own, then both. Also useful: with the paint window open, move the
**main** window to the iPad instead. Does the main window still update there?
## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
