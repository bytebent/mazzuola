## Mazzuola v0.0.0 — milestone 0: the skeleton

The empty app, ready for modelling to be added in milestone 1. Nothing can be modelled
yet.

- Light theme with a red accent for buttons, tabs and the active tool.
- Four views (Top, Front, Right, 3D), each switchable to any direction (top, bottom,
  front, back, left, right, 3D) from its header; Maximise / Restore per view; drag the
  bars between views to resize them (double-click resets).
- Grid in centimetres: è / + make it smaller / larger (1/8 cm to 512 cm),
  View → Set grid size… to type one, Shift+R shows/hides it, Shift+W turns snapping on/off.
- 2D views: wheel zooms toward the cursor, middle mouse or Space + left mouse pans.
- 3D view: right mouse orbits (around the origin), wheel zooms, middle mouse pans;
  Z over the 3D view starts fly mode (W A S D, Q/E down/up, Shift fast; Z or Esc stops).
- Cmd+0 brings every view back to the origin.
- Selection modes 1–4 (vertices, edges, faces, pieces), ready for milestone 1.
- Every planned shortcut is in the menus and in Help → Controls (F1), with the milestone
  that brings it. Please check the shortcuts.
- Texture view, Parts and Palette panels are in place, empty until their milestones.
- Uses no CPU while idle.
## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
