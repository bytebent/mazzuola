## Mazzuola v0.0.6 — iPad test, round 4

The tests showed it isn't Mazzuola: OpenGL apps (Mazzuola, Scalpellino) don't update on
the Sidecar screen, while apps like Safari and Discord do. Likely reason: a Mac with two
graphics chips, and OpenGL apps that by default lock themselves to one of them, so their
windows can't be shown on a display handled another way (like Sidecar's).

This build tells macOS that Mazzuola supports switching graphics chips (both the setting
in the app and the one in its Info.plist). Please try: start it fresh, move the whole app
to the iPad. Then, if that works, try the paint window there too.
## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
