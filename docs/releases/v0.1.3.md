## Mazzuola v0.1.3 — Typed values (alpha 1)

Exact values, copies in patterns, mirroring and flattening, plus what you asked for
after v0.1.2.

**Try this:**

- **Move / rotate / scale** (Cmd+T, Mesh menu): a small window that stays open while
  you type; the views show the result live, and you can still turn and zoom them.
  Values are added to where things are now (move cm, rotate degrees, scale %, and
  along the normal for faces), about the selection's centre, the world origin or a
  typed point. Return applies (one undo step), Esc cancels. It opens at zero each time.
- **Multi-Replicate** (Cmd+Shift+D): N copies, each one step further: offset, turn and
  scale per copy (optionally the offset scaling too), about the selection (travelling
  with the copies), the world origin or a typed point. A row, a ring round the origin,
  spiral stairs, a tapering tower. The copies end up selected. It remembers its values.
- **Duplicate** (Cmd+D): a copy in place, selected, ready to move.
- **Mesh menu:** Mirror X/Y/Z (flips the selection in place), Mirror clone X/Y/Z (a
  mirrored copy across the world origin: the other half of a symmetric model),
  Flatten (line points up on an axis at their average, lowest or highest), Snap points
  to grid (Cmd+B).
- **Since v0.1.2:** the arrows only show in the 3D view; the views start 3D / Top /
  Front / Right as in Scalpellino; the Vertex tool works on points only (pressing 2, 3
  or 4 in it switches to Select).

Next: v0.1.4, getting models out (glTF and OBJ export), reference images in the 2D
views, and the 175 cm figure. Tell me what feels wrong first.

## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
