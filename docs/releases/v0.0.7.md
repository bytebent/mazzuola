## Mazzuola v0.0.7 — cleanup after the iPad tests

v0.0.6 fixed the iPad: Mazzuola now tells macOS it supports switching graphics chips,
which OpenGL apps need to show on a Sidecar screen on a two-GPU Mac. This build tidies
up after the tests:

- **View → Paint window** stays: a second window to put on the iPad. For now it has the
  tool and palette buttons (painting arrives in milestone 6), a 3D view to turn by
  dragging, and what the pen reports.
- Panels can no longer be pulled out of the main window. That was the fragile part (the
  crash, and the Pencil not working in them); the paint window replaces it.
- The test switches in the paint window (frame counter, sync, refresh, redisplay) and
  the tap test are gone.
- Help → Pen and mouse test stays.
## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
