## Mazzuola v0.2.5.1 — Clean up, fixed (alpha 2)

A fix release after a code review of v0.2.5.

**Fixed:**

- **Delete / Dissolve on faces now really joins them.** Split a face (Subdivide), select
  the pieces and press Delete: you get the single face back, and the faces around it
  lose the extra points too. Before, the pieces stayed (or came back split differently).
- **Deleting a block of faces together with a face elsewhere** could shrink the wrong
  points, quietly changing the model's shape. Fixed.
- **Dissolving a point after Detach** could remove the other point at the same spot.
  Fixed.
- **Subdivide** with numbers that don't match a neighbour read memory it shouldn't
  (it was refused, but could have crashed). Fixed.

Nothing else changed. Next: v0.2.6 "Bevel, bridge, mirror", planned with you first.

## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
