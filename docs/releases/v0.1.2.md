## Mazzuola v0.1.2 — Points, edges, faces (alpha 1)

Below whole shapes: faces, edges and points, the Vertex tool, the axis arrows, edge
loops and rings, and rounded edges for boxes and cylinders.

**Try this:**

- **Modes:** 1 points, 2 edges, 3 faces, 4 whole pieces (or the buttons at the top of
  the tool bar). Switching converts what's selected: a face becomes its corners, four
  corners become the face between them, and so on.
- **Selecting:** a click picks one face, edge or point. In a 2D view, a click on a point
  takes all the points stacked there; on a face, the nearest one, and clicking again on
  the same spot gives the one behind. A rectangle in a 2D view takes everything inside,
  front and back; in the 3D view only what you can see. Cmd+click adds or removes.
- **Moving:** the selection box works as before (drag, Shift+drag to copy, handles,
  Option+drag a corner, rings). New: **X/Y/Z arrows** at the selection's centre; drag
  one to move along that axis only.
- **Vertex tool** (Shift+V, tool bar): press on any point and drag it straight away,
  no need to select it first. Grab a point that's already selected to move them all.
- **Edge loops:** double-click an edge for its loop (the belt all the way round),
  Shift+double-click for its ring (the ladder across). Also in the Select menu.
- **Grow / shrink:** Cmd++ / Cmd+è.
- **Delete** in point or edge mode removes the faces that use them.
- **Rounded edges:** box and cylinder, 1–3 faces across each edge, and how big the
  rounding is (the same size on every edge).

## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
