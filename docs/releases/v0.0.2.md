## Mazzuola v0.0.2 — paint window test

A test for painting on the iPad: **View → Paint window (test)** opens a second, real
Mazzuola window (not a panel pulled out of the main one). Put it on the iPad through
Sidecar and try it with the Apple Pencil:

- Tap the tool buttons, the colour swatches and **Tap test** (it counts taps).
- Drag on the 3D view to turn it; two-finger scroll zooms.
- The left strip shows what the pen reports (source, pressure, tilt).
- It follows the main window's grid (try è / + in the main window).
- Close it with its close button or the same menu item.

Nothing is painted yet: this only checks that the pen works in a second window.
Painting arrives in milestone 6.
## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
