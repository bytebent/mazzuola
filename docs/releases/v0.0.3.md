## Mazzuola v0.0.3 — paint window display test

In v0.0.2 the paint window took Pencil taps on the iPad but didn't redraw until it was
moved back to the Mac screen. This build changes how it hands its pictures to the
display (it now waits for the display like the main window does, which is the only
difference between the two), and adds a small display test in the paint window's left
strip:

- **Frames drawn**: counts up every time the window draws. If the number on the iPad
  stays still while you tap, the window isn't being shown; if it counts but nothing
  else changes, it's something else.
- **Sync to display** (on by default): the new behaviour. Turn it off to get v0.0.2's.

Please try the paint window on the iPad again and tell me what the counter does, with
the checkbox on and off.
## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
