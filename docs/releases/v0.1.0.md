## Mazzuola v0.1.0 — milestone 1: mesh basics

The first version that makes models.

- **Primitives:** plane, box (segments, rounded edges), cylinder, cone, tube, torus,
  sphere, geosphere, and **rocks** (triangles, roughness, stretch, flat bottom, quads,
  seed with New seed). Drag a box in a 2D view with the Primitives tool (**Shift+B**)
  or type the values in Properties; the preview is cyan; **Return** creates, **Esc**
  cancels.
- **Selecting:** vertices / edges / faces / pieces (**1–4**), click, **Cmd+click**, box
  select, grow / shrink, similar, edge loop / ring, hide / hide others / show all.
  Selection is pink.
- **Moving:** drag the selection in a 2D view (grid steps), drag the handles to scale,
  click the selection for rotate handles. **Esc** during a drag puts it back.
- **Typed:** Move / rotate / scale / copy (**Cmd+T**) with copies in a row or circle,
  Move points exactly, Snap to grid, Mirror (or mirrored copy), Flatten, Model pivot.
- **Reference images** in the 2D views (View → Reference images…): size, place, turn,
  opacity, in front or behind. They reload when you come back to Mazzuola.
- **Scale figure** (175 cm), lines over faces in 3D, frame selection (**Cmd+E**).
- **Files:** `.mazz` save / open (asks about unsaved changes), export `.glb`, `.gltf`,
  `.obj`. Undo / redo for every change.

Not yet: handles in the 3D view (use the 2D views or Cmd+T), textures (milestone 5).
## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
