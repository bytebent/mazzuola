## Mazzuola v0.1.0 — Boxes (alpha 1, first release)

The first release of the redone milestone 1 ("alpha 1"). It replaces the withdrawn
v0.1.0. Only boxes so far, but handled the way agreed: like Scalpellino's brushes.

**Try this:**

- **Tool bar on the left:** Select (Shift+S) and Primitives (Shift+B). Vert / Edge /
  Face / Piece at the top (only Piece works until v0.1.2). The status bar says what the
  active tool's mouse and keys do.
- **Draw a box:** Primitives, drag a rectangle in a 2D view. It shows in all four
  views; adjust it with the handles in any 2D view (its height in Front or Right), or
  type its size in Properties. Return creates it, Esc cancels. A new box takes its
  height from the last box you made or selected.
- **Select:** click a box; click again on the same spot for the one underneath;
  Cmd+click adds or removes; drag from empty space for a rectangle; Esc selects nothing.
- **The selection box:** drag inside it to move (snapped to the grid), Shift+drag to
  copy, drag a side or corner handle to resize (the opposite side stays), Option+drag a
  corner to rotate (15° steps; hold Shift too for free). In the 3D view, drag the
  coloured rings to rotate.
- **Delete**, **Undo / Redo** (Cmd+Z / Cmd+Shift+Z), **New / Open / Save / Save as**
  (Cmd+N / O / S / Shift+S), with "Save changes?" before closing unsaved work.

The `.mazz` file is plain text with clean numbers (`v 96 48 32`, never `1e+02`).

Next: v0.1.1, all the other shapes (cylinder, cone, tube, torus, sphere, geosphere,
plane) and the rock. Tell me what feels wrong first.

## Download

- **Intel Mac:** `Mazzuola-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Mazzuola.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Mazzuola.app`

Controls are listed in the README.
